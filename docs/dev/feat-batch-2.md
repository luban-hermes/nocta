## 各项改动

### 9 · 去掉说明性文字
- 原则：界面只用一句话说明「这个功能是做什么的」，怎么用 / 内部规则 / 环境变量等说明只留在 README；错误提示保留。
- 登录页、初始化页、添加弹窗（链接 / HTTP / 服务器）、左栏「规则模式」卡（整块删除）、空状态、监控卡、探针抽屉、AI 助手欢迎语、设置页各项说明按 backlog 审计清单逐条替换或删除。
- 设置页去掉「环境变量」徽章；AI「测试连接」直接使用当前表单里填写的内容（不必先保存）。

### 10 · 设置页左侧二级 Tab
- `SettingsPanel.tsx`：左侧竖排 Tab（图标 + 名称）：访问与显示 / AI / 服务监控 / 备份 / 账号，右侧只显示当前分组。
- 当前 Tab 写进 URL（`/admin?tab=ai`），刷新、分享、登录跳转后都保留（`AdminApp.tsx`、`admin/page.tsx`）。
- 窄屏（≤760px）Tab 变成顶部横向可滚动的一行，当前 Tab 自动滚动到可见位置。

### 11 · 拖动不再被裁切
- `ui/sortable.tsx`：拖起的卡片由 dnd-kit `DragOverlay` 渲染并 portal 到 `<body>`，不受父容器 `overflow` / `content-visibility`（绘制包含）裁切；原位置留半透明占位。站点、收藏内容、左侧分类栏、后台分类、抽屉里的链接列表统一使用。
- 拖起的副本为不透明背景（玻璃卡片不再透出底下的内容）。
- `.sites` 的 `content-visibility:auto` 性能优化保留。
- 站点卡片去掉原生 `title` 悬停提示。

### 12 · 宽屏居中
- `.app` / 顶栏 `max-width` 恢复 1440px 并居中，超宽屏两侧对称留白；去掉 ≥1800px 时放大网格的规则。
- 收藏内容瀑布流仍按容器宽度计算列数（v0.2.0 的 JS 列计算），在 1440px 内铺满。

### 13 · 站点多链接
- 数据：主链接仍在 `Site.url`（新增 `Site.urlNote` 备注），备用链接在新表 `SiteLink(url, note, sort)`，删除站点级联删除。
- 接口：`/api/sites/:id/links`（增删改排序）、`/api/sites/:id/merge`（把新粘贴的链接并入已有站点作为备用链接）。
- 添加弹窗：「+ 备用链接」可填多行；粘贴的链接与已有站点相似时提示「作为 X 的备用链接」一键合并。编辑抽屉里可增删链接、拖动排序（拖到第一位即成为主链接）。
- 卡片外观不变。左键打开主链接；右键菜单「打开」展开子菜单列出全部链接，带在线状态点和延迟。
- 可达性在**用户浏览器里**判断（`src/lib/linkprobe.ts`）：只对有备用链接的站点，`fetch(url, {mode:"no-cors", method:"HEAD"})` + 1.5 秒超时，最多 6 个并发；结果缓存 5 分钟。
- 自动切换：设置「访问与显示」里的「自动切换备用链接」开关（`siteFailover`，默认开启）——主链接不可达时左键打开第一个可达的备用链接；未测过时点击当下探测（先同步打开空白页避免被拦截，探测完再跳转）。
- 备份格式升到 v2（包含 `siteLinks`）；v1 备份仍可恢复（视为没有备用链接）。

## 已知限制

- `no-cors` 探测看不到 HTTP 状态码：站点返回 5xx 也会被当作「可达」；只能识别连不上 / DNS 失败 / 超时。
- 在 https 页面上无法探测 `http://` 链接（混合内容），状态显示为未知，自动切换时排在可达链接之后。
- 可达性结果只存在当前浏览器内存里，不写回服务器，也不在服务器之间共享。
